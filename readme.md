# 🎯 Auto Clicker - by MasEylan

Auto Clicker GUI sederhana untuk Windows. Dibuat dengan Python, memungkinkan klik otomatis di posisi kursor Anda dengan interval yang bisa disesuaikan. Mendukung pengaturan hotkey secara dinamis melalui penekanan tombol keyboard.

---

## 🇮🇩 Fitur (Bahasa Indonesia)

- Klik otomatis di posisi kursor.
- Interval klik bisa diatur (dalam detik).
- Pilih tombol mouse (kiri atau kanan).
- Mulai/Berhenti klik otomatis menggunakan hotkey.
- Ubah hotkey dengan menekan tombol secara langsung.
- Status indikator apakah clicker sedang berjalan atau tidak.
- GUI ringan, berwarna cerah, dan mudah digunakan.
- Hyperlink ke halaman GitHub MasEylan.
- Aplikasi tidak dapat di-resize.
- Dibuat dengan Python + tkinter + pyautogui + keyboard.

---

## 🇬🇧 Features (English)

- Automatically clicks at your cursor location.
- Set custom click interval (in seconds).
- Choose mouse button (left or right).
- Start/Stop auto clicking via hotkey.
- Dynamically change hotkey by pressing a key.
- Visual status showing whether it's running or stopped.
- Light, clean and colorful GUI design.
- Clickable link to MasEylan's GitHub.
- Fixed-size window (not resizable).
- Built with Python + tkinter + pyautogui + keyboard.
